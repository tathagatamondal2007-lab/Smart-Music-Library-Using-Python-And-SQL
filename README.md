# 🎵 Smart Music Library

A feature-rich, object-oriented desktop application designed for managing, organizing, and playing personal music collections. Built with an SQLite backend to store tracks persistently and Pygame for real-time local audio playback.

---

## ✨ Features

- 🎧 **Audio Playback**: Local music streaming and controls powered by Pygame.
- 📂 **Library Management**: Add, view, search, and edit track details dynamically.
- 📊 **Track Analytics**: Tracks play counts and keeps track of top-played songs.
- 🔍 **Advanced Filtering**: Filter your music collection by artist or genre.
- 💾 **Persistent SQLite Database**: Automatically manages storage inside user AppData directories for seamless persistence.
- 📦 **Standalone Application**: Can be packaged into a native Windows executable with an installer wizard.

---

## 🛠️ Tech Stack

| Technology | Role |
| :--- | :--- |
| **Python** | Core Application Logic |
| **SQLite3** | Relational Database for Persistence |
| **Pygame** | Audio Engine & Playback Controls |
| **Dataclasses** | Structured Data Models |
| **PyInstaller & Inno Setup** | Desktop Packaging & Installer Creation |

## 🚀 Getting Started

### Option 1: For End Users (Desktop App)

1. Download and run the standalone application setup executable.
2. Follow the setup wizard instructions.
3. Launch **Smart Music Library** directly from your Desktop or Start Menu—no extra setup or Python installation required!
